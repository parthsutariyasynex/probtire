01 — Identity

Logo

The B.Tire mark combines a bold geometric "B" in brand red with a precision wordmark. Both elements must appear together at their designed ratio — the B mark alone is not a standalone identity element.

On white — primary
On canvas
On brand yellow
On dark — reversed

Use

  • Always use the vector file — never raster exports or screenshots
  • Maintain clearspace equal to the height of the B mark on all sides
  • Use only on the four approved background colours shown above
  • Keep the wordmark and B mark proportional at all sizes

Avoid

  • Stretching, rotating, or cropping any part of the logo
  • Recolouring the B mark to anything other than red (#D20000) or white
  • Placing on photographic backgrounds without a solid colour panel behind
  • Using the wordmark without the B mark, or vice versa
02 — Color

Color System

Amber yellow is the single brand accent. Everything else is black, white, or a step in the gray scale. This restraint keeps the accent meaningful — if every element shouts yellow, nothing does.

Radius & Spacing

The UI skews square — radius-sm (3px) on buttons and inputs, radius-none on quantity controls and table cells. Only cards and modals use larger values. Never use rounded-lg on interactive controls.

06 — Voice & Tone

Voice & Tone

Al Talayi serves B2B fleet and retail buyers. Be direct, precise, and respect their time. Every error message, confirmation, and empty state is a customer touchpoint — treat them with the same care as the product page.

Direct

State facts. Drop hedges. "Ships today" — not "May ship today if ordered soon."

Expert

Speak the buyer's language — tyre size codes, load ratings, speed indices. Explain what's unfamiliar; never dumb it down.

Actionable

Errors name the fix. Confirmations give the next step. No apologies, no corporate filler, no dead ends.
